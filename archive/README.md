# Архив

## `art-leto-cra/`

Предыдущий сайт «Арт-лето» (Create React App). Сохранён при переходе на лендинг «Рождественский детектив» (Vite).

Чтобы снова собрать старую версию:

```sh
cd archive/art-leto-cra
npm install
npm run build
```

В git также есть ветка `backup/art-leto-2026-10-12` и тег `art-leto-backup-2026-10-12`.
